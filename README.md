# Anmol Shrestha — Computer Engineer
A modern, high-performance, and responsive developer portfolio website built for **Anmol Shrestha** (Computer Engineering Student at IOE, Pulchowk Campus; Aspiring AI/ML Engineer & Data Scientist).

Built with **React 19**, **TypeScript**, **Tailwind CSS**, and **Lucide Icons**, featuring an interactive neural network particle canvas, custom project telemetry dashboards, deep-dive architectural modals, an academic timeline, and persistent dark/light theme toggle.

---

## ✨ Features

- **Futuristic & Clean Aesthetic**: Deep charcoal / slate palette with electric blue, cyan, and violet accents.
- **Interactive Neural Network Canvas**: Custom HTML5 Canvas rendering dynamic synaptic nodes and signal pulses that react subtly to cursor movement (respects `prefers-reduced-motion`).
- **Decoupled Architecture**: All personal bio details, skill sets, project metadata, education, and achievements are organized in `src/data/portfolioData.ts` for simple, 1-minute updates.
- **Rich Project Dashboards & Telemetry**:
  - **Poker Nexus**: Monte Carlo rollout simulation matrix, card hands, equity distribution bar.
  - **Risk Scoring & Prioritization**: Supervised financial risk ranker, feature attribution breakdown (SHAP).
  - **World Cup Predictor**: FIFA match progression predictor with rolling team form and win/draw/loss distribution.
  - **Sentiment Analysis**: NLP preprocessing token stream and confidence distribution.
- **Deep-Dive Architecture Modals**: Clicking *"View Details"* on any project reveals full pipeline diagrams, methodologies, and technical contributions.
- **Academic Consistency Showcase**: Highlights consistent 3.90/4.00 GPA across SEE and +2 Science at St. Xavier's College, leading to IOE Pulchowk Campus.
- **Validated Contact System**: Client-side validation with instant email client launcher (`mailto:`) and one-click formatted message clipboard copy.
- **Theme Switcher**: Instant Dark / Light mode toggle with `localStorage` persistence and automatic system preference detection.
- **Fully Responsive & Accessible**: Mobile navigation drawer, semantic HTML5 tags, keyboard navigation focus rings, and zero horizontal overflow.

---

## 🛠 Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 6+
- **Styling**: Tailwind CSS
- **Icons**: Lucide React + Custom SVG Brand Icons
- **Typography**: Inter & JetBrains Mono (via Google Fonts)
